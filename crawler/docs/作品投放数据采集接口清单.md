# 作品投放数据采集模块 - 接口清单与数据字段说明

## 1. 接口概述

作品投放数据采集模块主要采集星图平台的作品投放数据，通过 `GetItemTrendStat` 接口获取作品的详细统计数据。

### 1.1 主要接口
- **接口地址**: `https://www.xingtu.cn/h/api/gateway/handler_get/`
- **接口方法**: GET
- **服务名称**: `data.AdStarDataService`
- **方法名称**: `GetItemTrendStat`
- **用途**: 获取作品的投放统计数据，包括播放量、互动数据、趋势分析等

## 2. 接口参数

### 2.1 必需参数
| 参数名 | 类型 | 示例值 | 说明 |
|--------|------|--------|------|
| `item_id` | String | `7584864709501832494` | 作品ID，抖音视频的唯一标识 |
| `traffic_type` | Integer | `1` | 流量类型：1=全部流量, 2=自然流量, 3=付费流量 |
| `user_role` | Integer | `1` | 用户角色：1=广告主, 2=达人 |
| `service_name` | String | `data.AdStarDataService` | 服务名称 |
| `service_method` | String | `GetItemTrendStat` | 服务方法名 |
| `sign_strict` | String | `1` | 严格签名模式 |
| `sign` | String | `a1b2c3d4e5f6...` | 请求签名，通过MD5算法计算 |

### 2.2 签名算法
签名算法基于以下步骤：
1. 将所有参数按key进行字典序排序
2. 按照 `key+value` 格式拼接（标量值）或 `key+key` 格式拼接（复杂类型）
3. 添加固定盐值 `e9fefef711becf4c3d7bfef829578b0c`
4. 使用MD5进行哈希计算

## 5. 采集功能特性

### 5.1 支持的流量类型
- **全部流量** (`traffic_type=1`): 包含自然流量和付费流量的总和
- **自然流量** (`traffic_type=2`): 仅包含自然推荐流量
- **付费流量** (`traffic_type=3`): 仅包含广告投放流量

### 5.2 支持的用户角色
- **广告主** (`user_role=1`): 以广告主身份查看数据
- **达人** (`user_role=2`): 以达人身份查看数据

### 5.3 数据采集频率控制
- 支持QPS控制（默认0.5，即每2秒1次请求）
- 可配置不同账号进行轮换采集
- 支持批量采集功能

## 6. 采集状态码说明

| 状态码 | 含义 | 处理方式 |
|--------|------|----------|
| `0` | 成功 | 正常处理数据 |
| `10255` | 权限错误 | 检查Cookie和star_id是否匹配 |
| 其他 | 其他错误 | 记录错误日志 |

## 7. 数据更新机制

### 7.1 实时更新
- 每次采集成功后，`item_delivery_summary` 表会实时更新最新数据
- `total_crawl_count` 会递增

### 7.2 历史追踪
- 所有采集历史保存在 `item_delivery_raw_archive` 表中
- 可追溯任意时间点的数据变化

## 8. 数据质量保证

### 8.1 数据验证
- 基础数据和实时数据的一致性检查
- 数值范围合理性验证
- 时间序列数据的连续性检查

### 8.2 错误处理
- API错误时记录详细错误信息
- 网络异常时自动重试
- Cookie过期时及时提醒更新

该模块能够全面采集作品投放数据，提供完整的数据追踪和分析能力。
