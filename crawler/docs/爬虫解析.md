## 3. 代理轮换与账号切换触发条件

### 3.1 代理轮换（ScrapeProxyPool）

| 触发条件 | 代码位置 | 行为 |
|----------|----------|------|
| **每次请求** | `get_next_proxy()` | Round-Robin 轮换 `current_index % len(healthy_proxies)` |
| **健康检测失败** | `_is_healthy()` | 失败率 > 50%（滑动窗口20次），标记为不健康 |
| **TTL过期** | `_should_refresh()` | 超过 ttl_hours（默认3小时），触发后台刷新 |
| **代理替换** | `_handle_replace_proxy()` | 失败率过高且样本>=10，后台线程替换单个代理 |

```python
# pool.py#L125-L157
def get_next_proxy(self) -> IpInfoModel:
    with self._lock:
        # 检查TTL刷新
        if self._should_refresh():
            self._refresh_queue.put(('refresh_pool', None))
        
        # 过滤健康代理
        healthy_proxies = [p for p in self.proxies if self._is_healthy(self._proxy_key(p))]
        
        # Round-Robin轮换
        proxy = healthy_proxies[self.current_index % len(healthy_proxies)]
        self.current_index += 1
        return proxy
```

### 3.2 账号切换（SessionManager + AccountPool）

| 触发条件 | 代码位置 | 行为 |
|----------|----------|------|
| **每次acquire_session** | `select_account(LEAST_USED)` | 选择 use_count 最少的账号 |
| **Cookie过期** | `_is_cookie_valid()` | status != ACTIVE 或 expires_at < now，跳过该账号 |
| **错误次数过多** | `AccountModel.is_available()` | error_count >= 5，账号标记为 ERROR |
| **账号被锁定** | `acquire_account()` | FileLock 锁定，跳过正在使用的账号 |

## 4. 限速器协同机制

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                              限速器层级架构                                      │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│   ┌───────────────────────────────────────────────────────────────────────────┐ │
│   │                  GlobalLimiter (全局限速器)                               │ │
│   │                  TimeWindowQPSLimiter(qps=domain_qps)                     │ │
│   │                  作用: 控制对整个API域名的总请求速率                        │ │
│   └───────────────────────────────────────────────────────────────────────────┘ │
│                                    │                                            │
│          ┌─────────────────────────┼─────────────────────────┐                  │
│          ▼                         ▼                         ▼                  │
│   ┌─────────────┐           ┌─────────────┐           ┌─────────────┐          │
│   │ ProxyLimiter│           │ ProxyLimiter│           │ ProxyLimiter│          │
│   │ (Proxy A)   │           │ (Proxy B)   │           │ (Proxy C)   │          │
│   │ qps=1       │           │ qps=1       │           │ qps=1       │          │
│   └─────────────┘           └─────────────┘           └─────────────┘          │
│                                                                                 │
│   ┌───────────────────────────────────────────────────────────────────────────┐ │
│   │                  ProxyLimiterPool (对象池)                                │ │
│   │                  复用限速器实例，降低内存占用                               │ │
│   │                  max_pool_size=10                                         │ │
│   └───────────────────────────────────────────────────────────────────────────┘ │
│                                                                                 │
│   ┌───────────────────────────────────────────────────────────────────────────┐ │
│   │                  CombinedLimiter (组合限速器)                             │ │
│   │                  def acquire(self):                                       │ │
│   │                      self.global_limiter.acquire()  # 先全局               │ │
│   │                      self.proxy_limiter.acquire()   # 后代理               │ │
│   └───────────────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────────────┘
```

**设计原理**：
- **全局限速器**: 防止对API服务器造成过大压力，所有账号+代理共享
- **代理限速器**: 防止单个代理IP被封，每个代理独立限速
- **对象池复用**: 避免为每个代理创建新的限速器实例

## 5. 异常处理与故障恢复机制

### 5.1 分层异常处理

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                            RetryHandler 异常处理                                 │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  HTTP 200 ──────────────────────────────> 成功，重置 consecutive_401 计数器     │
│                                                                                 │
│  HTTP 500/502/503 ──> 指数退避重试 ──────> backoff_ms * 2^attempt + jitter      │
│                       最多 retry_max 次                                         │
│                                                                                 │
│  HTTP 429/403 ──────> 指数退避 + 额外冷却 ─> cooldown_on_429_403_ms (2秒)       │
│                                                                                 │
│  HTTP 401 ──────────> consecutive_401++ ──> 达到阈值(3)则暂停 pause_on_401_ms  │
│                       暂停后重置计数器                                          │
│                                                                                 │
│  其他状态码 ────────> 跳过该页，记录日志                                        │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 代理池故障恢复

```python
# pool.py#L159-L178
def update_proxy_health(self, proxy: IpInfoModel, success: bool):
    key = self._proxy_key(proxy)
    with self._lock:
        # 记录到滑动窗口
        self.proxy_results[key].append(success)
        
        # 检查是否需要替换（失败率 > threshold 且样本 >= 10）
        if not self._is_healthy(key) and len(self.proxy_results[key]) >= 10:
            # 提交后台替换任务（非阻塞）
            self._refresh_queue.put(('replace_proxy', proxy))
```

### 5.4 完整的故障恢复流程

```
请求失败
    │
    ├─> 状态码分析
    │       │
    │       ├─ 401 (认证失败)
    │       │      └─> 1. 更新 account.error_count++
    │       │          2. 如果 consecutive_401 >= 3，暂停 pause_on_401_ms
    │       │          3. 如果 error_count >= 5，标记账号为 ERROR，下次选择其他账号
    │       │
    │       ├─ 429/403 (限速/禁止)
    │       │      └─> 1. 更新 proxy 健康度 (success=False)
    │       │          2. 如果代理失败率 > 50%，触发后台替换
    │       │          3. 额外冷却 cooldown_on_429_403_ms
    │       │
    │       └─ 5xx (服务器错误)
    │              └─> 指数退避重试，不影响账号/代理健康度
    │
    └─> session_manager.release_session(session, success=False)
            │
            └─> binding.scrape_proxy_pool.update_proxy_health(proxy, False)
                    │
                    └─> 滑动窗口记录失败，触发健康检测
```
