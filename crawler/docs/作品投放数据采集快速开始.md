# 作品投放数据采集模块 - 快速开始

## 🚀 5分钟快速上手

### 步骤1: 获取有效签名（重要！）

当前实现的签名算法是占位符，需要从浏览器获取真实签名：

1. 打开浏览器开发者工具（F12）
2. 访问作品投放数据页面：
   ```
   https://www.xingtu.cn/ad/creator/item-delivery-data/7584864709501832494
   ```
3. 在 Network 标签中搜索 `handler_get`
4. 找到包含 `GetItemTrendStat` 的请求
5. 复制请求URL中的 `sign` 参数值

示例URL:
```
https://www.xingtu.cn/h/api/gateway/handler_get/?item_id=7584864709501832494&traffic_type=1&user_role=1&service_name=data.AdStarDataService&service_method=GetItemTrendStat&sign_strict=1&sign=45f8bf7203943ddd09a4bd2a8a1e6ed6
                                                                                    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                                                                                    复制这个sign值
```

### 步骤3: 批量采集

创建作品ID文件 `my_items.txt`:
```

```

运行批量采集:
```bash
python tools/fetch_item_delivery_data.py \
  --item-ids-file my_items.txt \
  --sign "你的sign值" \
  --qps 0.3 \
  --output results.json \
  --pretty
```

## 🔧 Python代码调用示例

```python
#!/usr/bin/env python3
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).parent.parent))

from adapters.xingtu import ItemDataClient
from services.account_config import get_star_id_by_account

# 获取star_id
star_id = get_star_id_by_account("account1")

# 初始化客户端
client = ItemDataClient(
    star_id=star_id,
    cookie_file="tools/account_manager/config/accounts/account1/cookies.txt",
    qps=0.5,
)

try:
    # 获取作品数据
    data = client.get_item_trend_stat(
        item_id="7584864709501832494",
        sign="你的sign值",  # 从浏览器获取
    )
    
    # 提取核心字段
    extracted = client.extract_essential_fields(data)
    
    # 打印关键指标
    stats = extracted['realtime_stats']
    print(f"播放量: {stats['play_count']:,}")
    print(f"完播率: {stats['finish_rate']:.2%}")
    print(f"点赞率: {stats['like_rate']:.2%}")
    
finally:
    client.close()
```

## ⚠️ 常见问题

### Q1: 提示"账号 account1 未配置star_id"

**解决方案:**
```bash
# 检查账号配置
cat tools/account_manager/config/account_pool.json

# 确保account1有star_id配置
{
  "accounts": [
    {
      "account_id": "account1",
      "star_id": "1843934177451019",
      ...
    }
  ]
}
```

### Q2: 提示"用户未登录 (11001)"

**解决方案:**
```bash
# 检查cookies文件
cat tools/account_manager/config/accounts/account1/cookies.txt

# 重新登录星图平台并更新Cookie
# 1. 浏览器登录 https://www.xingtu.cn
# 2. F12 -> Application -> Cookies
# 3. 复制所有Cookie到cookies.txt
```

### Q3: 签名验证失败

**原因:** sign参数可能有时效性或与item_id绑定

**解决方案:**
1. 每次采集前从浏览器获取最新sign
2. 或者实现真实的签名算法（需要JS逆向）

## 📊 数据字段说明

### base_stats（基础统计）
- `play_count`: 总播放量
- `cpm`: 千次展示成本
- `cpe`: 每次互动成本
- `five_sec_rate`: 5秒播放率

### realtime_stats（实时统计）
- `play_count`: 播放量
- `finish_count`: 完播量
- `finish_rate`: 完播率
- `like_count`: 点赞量
- `like_rate`: 点赞率
- `comment_count`: 评论量
- `comment_rate`: 评论率
- `share_count`: 转发量
- `share_rate`: 转发率

### trend_data（趋势数据）
分时数据数组，包含每个时间点的指标
