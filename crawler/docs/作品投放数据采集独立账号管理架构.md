# 作品投放数据采集独立账号管理架构

## 架构概述

作品投放数据采集模块已实现完全独立的账号和Cookie管理机制，与达人详情采集模块完全隔离。

## 核心文件清单

### 1. 账号配置文件

```
crawler/
├── tools/
│   └── account_manager/
│       └── config/

│           ├── item_delivery_account_pool.json      # 作品数据账号池（新增）
```

## 技术实现

### 1. 独立的账号配置服务

`services/item_account_config.py` 提供以下API：

```python
# 获取star_id
get_item_star_id_by_account(account_id: str) -> Optional[str]

# 获取账号信息
get_item_account_info(account_id: str) -> Optional[Dict]

# 获取Cookie文件路径
get_item_cookie_file_path(account_id: str) -> Optional[str]

# 列出所有账号
list_all_item_accounts() -> List[Dict]

# 获取可用账号（自动轮换）
get_available_item_account() -> Optional[Dict]
```

### 2. 采集工具的三种使用模式

#### 模式1：作品数据专用账号（推荐）

```bash
python tools/fetch_item_delivery_data.py \
  --item-ids-file tools/item_ids_example.txt \
  --account item_account_1 \
  --qps 0.5
```

- 使用 `item_delivery_account_pool.json` 配置
- Cookie从 `accounts/item_account_1/cookies.txt` 读取
- 完全隔离，避免冲突

#### 模式2：兼容模式（使用达人采集账号）

```bash
python tools/fetch_item_delivery_data.py \
  --item-ids-file tools/item_ids_example.txt \
  --account account1 \
  --use-author-account \
  --qps 0.5
```

- 使用 `account_pool.json` 配置
- Cookie从 `accounts/account1/cookies.txt` 读取
- 仅用于临时测试

#### 模式3：自定义配置

```bash
python tools/fetch_item_delivery_data.py \
  --item-ids-file tools/item_ids_example.txt \
  --star-id "1843934177451019" \
  --cookie "sessionid=xxx; ..." \
  --qps 0.5
```

- 完全自定义star_id和cookie
- 不依赖配置文件

### 3. 签名算法集成

作品数据采集使用独立的签名算法（MD5 + 盐值）：

```python
# ItemDataClient._calculate_sign()

sign = hashlib.md5(sign_str.encode("utf-8")).hexdigest()
```

## 配置示例

### item_delivery_account_pool.json

```json
{
  "description": "作品投放数据采集专用账号池",

}
```

## 使用流程

### 初始配置

1. 登录星图平台，获取star_id
2. 复制Cookie到 `accounts/item_account_1/cookies.txt`
3. 编辑 `item_delivery_account_pool.json`，填写star_id
4. 将账号status设置为 `active`

### 运行测试

```bash
# 测试配置
python services/item_account_config.py

# 测试采集功能
python tools/test_item_delivery.py

# 实际采集
python tools/fetch_item_delivery_data.py \
  --item-id 7584864709501832494 \
  --pretty
```

## 故障排查

### 问题1：报10255权限错误

**原因**：Cookie与star_id不匹配

**解决**：
1. 确认使用的是专用账号的Cookie
2. 检查 `item_delivery_account_pool.json` 中的star_id是否正确
3. 重新登录并更新Cookie

### 问题2：账号未配置star_id

**原因**：配置文件中star_id为空

**解决**：
1. 登录星图平台
2. 从Network请求中提取star_id
3. 更新配置文件

### 问题3：Cookie文件未找到

**原因**：Cookie文件路径错误或文件不存在

**解决**：
1. 检查 `accounts/item_account_1/` 目录是否存在
2. 确认 `cookies.txt` 文件已创建
3. 检查配置中的 `cookie_file` 路径

## 最佳实践

1. **生产环境必须使用专用账号**
   - 避免与其他模块冲突
   - 确保数据采集稳定性

2. **定期更新Cookie**
   - 建议每周检查一次
   - 出现401错误立即更新

3. **合理设置QPS**
   - 作品数据接口：0.3 - 0.5
   - 批量采集时适当降低

4. **监控账号状态**
   - 记录错误次数
   - 及时切换故障账号

## 扩展能力

### 添加新账号

1. 在 `item_delivery_account_pool.json` 中添加配置：

```json
{
  "account_id": "item_account_2",
  "account_name": "作品数据账号2",
  "star_id": "your_star_id",
  "status": "active",
  "cookie_file": "tools/account_manager/config/accounts/item_account_2/cookies.txt"
}
```

2. 创建Cookie文件：

```bash
mkdir -p tools/account_manager/config/accounts/item_account_2
# 然后复制Cookie到该目录的cookies.txt文件
```

### 账号轮换策略

当前支持的轮换策略：
- `least_used`：使用次数最少的账号
- `round_robin`：轮换使用（待完善）

可通过修改 `rotation_strategy` 字段切换。
