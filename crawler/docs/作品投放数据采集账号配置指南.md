# 作品投放数据采集账号配置指南

## 为什么需要独立账号管理？

作品投放数据采集模块访问的是不同的API端点（`/h/api/gateway/handler_get/`），与达人详情采集（`/gw/api/`）使用不同的URL。因此需要：

1. **独立的Cookie管理** - 避免与其他爬虫模块的Cookie冲突
2. **独立的star_id配置** - 确保账号身份与Cookie一致，避免10255权限错误
3. **独立的QPS控制** - 作品数据接口可能有不同的频率限制

## 配置步骤

### 1. 配置账号池

编辑配置文件：`tools/account_manager/config/item_delivery_account_pool.json`

```json
{
  "description": "作品投放数据采集专用账号池",
  "accounts": [
    {
      "account_id": "item_account_1",
      "account_name": "作品数据账号1",
      "username": "your_email@example.com",
      "star_id": "1843934177451019",  // 重要：从星图平台获取
      "status": "active",
      "cookie_file": "tools/account_manager/config/accounts/item_account_1/cookies.txt"
    }
  ]
}
```

### 2. 获取star_id

登录星图平台后，访问任意作品投放数据页面，从URL中提取star_id：

```
https://www.xingtu.cn/ad/creator/item-delivery-data/7584864709501832494
```

然后查看Network请求，找到包含star_id的参数。

### 3. 配置Cookie

**方法一：手动复制（推荐）**

1. 浏览器登录星图平台
2. F12打开开发者工具 → Network
3. 访问作品投放数据页面
4. 复制任意请求的Cookie值
5. 粘贴到 `tools/account_manager/config/accounts/item_account_1/cookies.txt`

```bash
# 文件内容示例（直接粘贴完整Cookie字符串）
sessionid=abc123; star_id=1843934177451019; ...
```

**注意**：Cookie必须与配置的star_id对应，否则会报10255权限错误！

### 4. 验证配置

运行测试脚本验证配置是否正确：

```bash
cd /Users/samuel/Desktop/系统开发/crawler
python services/item_account_config.py
```

## 使用方式

### 方式一：使用作品数据专用账号（默认，推荐）

```bash
# 使用默认的item_account_1
python tools/fetch_item_delivery_data.py \
  --item-ids-file tools/item_ids_example.txt \
  --qps 0.5

# 使用其他作品数据专用账号
python tools/fetch_item_delivery_data.py \
  --item-ids-file tools/item_ids_example.txt \
  --account item_account_2 \
  --qps 0.5
```

### 方式二：兼容模式（使用达人采集账号池）

如果您还没有配置作品数据专用账号，可以临时使用达人采集账号：

```bash
python tools/fetch_item_delivery_data.py \
  --item-ids-file tools/item_ids_example.txt \
  --account account1 \
  --use-author-account \
  --qps 0.5
```

**注意**：兼容模式仅用于临时测试，生产环境强烈建议使用独立账号！

### 方式三：自定义配置

完全自定义star_id和cookie：

```bash
python tools/fetch_item_delivery_data.py \
  --item-ids-file tools/item_ids_example.txt \
  --star-id "1843934177451019" \
  --cookie "sessionid=xxx; ..." \
  --qps 0.5
```

## 账号池架构对比

### 达人采集账号池
- 配置文件：`tools/account_manager/config/account_pool.json`
- 账号ID：`account_1`, `account_2`, `account_3`
- API端点：`/gw/api/`
- 用途：达人详情、达人列表等

### 作品数据账号池（新增）
- 配置文件：`tools/account_manager/config/item_delivery_account_pool.json`
- 账号ID：`item_account_1`, `item_account_2`, ...
- API端点：`/h/api/gateway/handler_get/`
- 用途：作品投放数据、作品趋势统计等

## 常见问题

### Q1: 为什么需要独立的账号池？
A: 不同API端点可能需要不同的Cookie和权限设置，独立管理避免相互干扰。

### Q2: Cookie过期怎么办？
A: 重新登录星图平台，按照"配置Cookie"步骤更新Cookie文件。

### Q3: 如何添加多个账号？
A: 在`item_delivery_account_pool.json`中添加新账号配置，并创建对应的Cookie文件目录。

### Q4: 报10255权限错误？
A: 检查Cookie和star_id是否匹配，必须使用同一账号的Cookie和star_id。

## 最佳实践

1. **生产环境使用独立账号池** - 避免与其他采集模块冲突
2. **定期检查Cookie有效性** - 建议每周更新一次
3. **合理设置QPS** - 作品数据接口建议QPS ≤ 0.5
4. **记录账号使用情况** - 出现错误时便于排查
